# Uso de agentes de IA nas quatro AGES

Fonte: relato do autor fornecido na conversa em 18/11/2026.

- AGES I e II: uso pouco frequente. Segundo sua experiência, as ferramentas ainda estavam em estágio inicial e cometiam erros com frequência.
- AGES III: passou a usar agentes com muito mais frequência para desenvolvimento e revisão de código. Combinava skills e contexto organizado no Obsidian para melhorar a adequação das respostas. Depois, fazia revisão visual/manual para encontrar inconsistências.
- AGES IV: além do código, a equipe utilizou agentes para gestão, criando issues no GitHub a partir do contexto do levantamento de requisitos.
- Os integrantes da AGES IV criaram um repositório compartilhado com contexto em arquivos `.md` para apoiar os agentes no desenvolvimento de código e de issues. O autor comparou a abordagem ao uso anterior do Obsidian, agora com informações compartilhadas entre os colegas.

Não foram informados nomes ou versões dos agentes, exemplos de erros específicos, métricas de acerto ou a URL do repositório compartilhado. O texto não atribui números de produtividade nem trata o relato como comparação medida entre ferramentas.
